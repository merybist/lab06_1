# Лабораторна робота № 6.1

**Дисципліна:** Алгоритмізація та програмування  
**Тема:** Пошук елементів одновимірного масиву ітераційним та рекурсивним способом  
**Варіант:** 23  

## Умова завдання
Сформувати одновимірний масив цілих чисел $t$ із 20 елементів у діапазоні значень від -14 до 7 за допомогою генератора випадкових чисел. Вивести масив на екран. Обчислити кількість та суму тих елементів, які задовольняють критерію: **всі додатні з індексами, крім кратних 4** (`t[i] > 0 && i % 4 != 0`). Замінити нулями ці елементи та вивести результат і модифікований масив.

1. **Спосіб 1 (ітераційний):** всі дії реалізовано за допомогою окремих ітераційних функцій (`Lab_06_1_it.cpp`).
2. **Спосіб 2 (рекурсивний):** всі дії реалізовано за допомогою окремих рекурсивних функцій без циклів (`Lab_06_1_rec.cpp`).

## Структура репозиторію
- `Lab_06_1_it.cpp` — ітераційна програма.
- `Lab_06_1_rec.cpp` — рекурсивна програма.
- `tests/UnitTest_06_1_it.cpp` — модульні тести для ітераційної програми (doctest).
- `tests/UnitTest_06_1_rec.cpp` — модульні тести для рекурсивної програми (doctest).
- `tests/doctest.h` — бібліотека для юніт-тестування doctest.
- `reports/` — оформлені звіти у форматі `.docx`.
- `.vscode/` — конфігурація завдань збірки, відладки та інтеграції тестів у VS Code.

## Збірка та запуск

### Ітераційний варіант
```bash
clang++ -std=c++17 Lab_06_1_it.cpp -o Lab_06_1_it && ./Lab_06_1_it
```

### Рекурсивний варіант
```bash
clang++ -std=c++17 Lab_06_1_rec.cpp -o Lab_06_1_rec && ./Lab_06_1_rec
```

### Модульні тести
```bash
clang++ -std=c++17 -I./tests tests/UnitTest_06_1_it.cpp -o UnitTest_06_1_it && ./UnitTest_06_1_it
clang++ -std=c++17 -I./tests tests/UnitTest_06_1_rec.cpp -o UnitTest_06_1_rec && ./UnitTest_06_1_rec
```
